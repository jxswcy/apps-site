NuType Privacy Policy

Effective date: 2026-06-05. Last reviewed: 2026-06-11.

NuType is a macOS voice input tool. Its privacy principle is simple: user data stays under user control. The developer does not operate an audio, text, or AI proxy server and does not collect user audio, transcribed text, API keys, history, or personal dictionary content.

Data We Do Not Collect

The NuType developer does not intentionally collect, view, sell, or share:

  • User-recorded audio.
  • Speech recognition text, cleaned text, local history, correction samples, personal dictionary entries, or quality analysis results.
  • AI or ASR API keys configured by the user.
  • Content inserted into other apps through NuType.
  • Advertising, cross-app tracking, or data broker data.

NuType does not include advertising SDKs, analytics SDKs, third-party login SDKs, or crash reporting SDKs.

Data Stored On Device

NuType stores the minimum data needed to provide its core features on the user's Mac:

  • Settings such as provider, base URL, model name, hotkey, language, history retention, and sync options.
  • Local history, including recognition text, cleaned text, timestamps, quality issues, and user corrections.
  • Personal dictionary entries and candidate terms.
  • Premium weekly usage records.

API keys are stored only in the macOS Keychain. They are not written to settings files, local history, exported snapshots, or iCloud sync data.

Microphone and Speech Recognition

NuType needs microphone permission to record speech. If the user selects Apple Speech, NuType requests Apple's system speech recognition permission. The user may also choose a local model or an external ASR provider they configure themselves.

If the user selects a local model, audio and text are processed locally on the user's device. If the user selects an external ASR or AI provider, NuType sends only the data required for that request directly from the user's device to the provider URL configured by the user, using the user's own API key. The developer does not proxy, store, or inspect those requests.

External providers process data according to their own terms and privacy policies. Users should review provider data retention, training, logging, and compliance terms before configuring an external service.

iCloud Sync

NuType's optional iCloud sync can synchronize non-sensitive data selected by the user across devices signed in to the same Apple ID. This can include dictionary entries, non-sensitive settings, recent history, and correction samples. API keys are not included in iCloud sync.

iCloud data is handled by Apple's iCloud services. The NuType developer cannot access the user's private iCloud data. Users can turn off iCloud sync in NuType settings or manage related data through macOS iCloud settings.

In-App Purchase

NuType Pro uses Apple StoreKit and App Store In-App Purchase. Purchases and payments are processed by Apple. NuType reads StoreKit purchase state only to unlock Pro features. The developer does not receive or store payment card information in the app.

App Store Privacy Disclosure

NuType does not track users for advertising, does not sell user data to data brokers, and does not combine app data with third-party data for advertising or advertising measurement.

If App Store Connect requires disclosure for optional external ASR or AI requests, NuType uses the following basis:

  • Audio Data: used for App Functionality, not for Tracking.
  • Other User Content: used for App Functionality, not for Tracking.
  • Linked to User: the developer does not link this data to user identity. If a user-configured external provider links requests to the user's provider account, that relationship is controlled by the provider.

User Controls and Deletion

Users can control or delete NuType data through the app and macOS:

  • Turn off local history or change the retention policy.
  • Delete local history.
  • Turn off iCloud sync.
  • Edit or delete personal dictionary entries.
  • Clear or replace API keys.
  • Use "Clear local data and API keys" to delete local history, dictionary entries, Keychain API keys, local Premium usage records, and the iCloud sync snapshot, and to reset non-sensitive settings with iCloud sync turned off. Apple StoreKit purchase records are not affected.
  • Revoke microphone, speech recognition, accessibility, and automation permissions in macOS System Settings.

NuType currently has no account system, so there is no developer-hosted account deletion flow.

Children's Privacy

NuType is intended for general productivity use and is not directed to children under 13. The developer does not knowingly collect personal information from children.

Policy Updates

If NuType adds accounts, a developer-owned cloud service, advertising, analytics SDKs, crash reporting SDKs, third-party login, cross-device API key sync, or any other feature that changes the data boundary, this privacy policy and App Store privacy disclosure must be updated before release.
