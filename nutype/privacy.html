NuTypePrivacy Policy

NuType is a local-first Mac voice input tool. Audio, recognized text, API keys, history, and dictionary data stay under your control.

Data we do not collect

The developer does not intentionally collect, view, sell, or share your recorded audio, recognized text, cleaned text, API keys, personal dictionary entries, inserted content, or advertising identifiers. NuType does not include advertising SDKs, analytics SDKs, third-party login SDKs, or crash reporting SDKs.

Data stored on your Mac

NuType stores settings, local history, quality notes, user corrections, personal dictionary entries, and premium usage records only to provide app features. API keys are stored in macOS Keychain and are not written to local history, exported snapshots, or iCloud sync data.

Microphone, speech, and providers

NuType requests microphone permission to record speech. Apple Speech is used only when selected. If you choose a local model, processing stays on your Mac. If you choose an external ASR or AI provider, NuType sends only the data required for that request directly to the provider URL and API key you configure.

iCloud sync and purchases

Optional iCloud sync may synchronize non-sensitive settings, dictionary entries, recent history, and correction samples across devices signed in to the same Apple ID. API keys are not included. NuType Pro purchases are processed by Apple StoreKit; NuType reads purchase state only to unlock Pro features.

User controls and deletion

You can turn off history, delete local history, edit dictionary entries, clear or replace API keys, turn off iCloud sync, and revoke microphone, speech recognition, accessibility, or automation permissions in macOS System Settings.

Contact

For support and privacy questions, email jxswcy@gmail.com. Do not include API keys, private recordings, Apple ID credentials, or payment information in support requests.

Privacy at a glance

NuType does not run a developer-owned audio, text, or AI proxy server. Your data is processed locally or sent directly to the provider you configure.

  • No advertising, analytics, or tracking SDKs.
  • API keys stay in macOS Keychain.
  • External providers are used only when you configure them.
  • Local data can be cleared from the app and macOS settings.
