NuType Support

NuType 1.0 for macOS. Last reviewed: 2026-06-11.

NuType is a macOS voice input tool for recording speech, converting it to text, cleaning filler words, and inserting the result into the current text field.

Support email: support@jxswcy.top.

For privacy questions, purchase restore issues, provider setup problems, or App Store review support, include the NuType version, macOS version, selected provider, and the exact error message shown in the app.

Common Setup Steps

  1. Open NuType and go to Settings.
  2. Grant microphone permission when prompted.
  3. Grant speech recognition permission only if Apple Speech is selected.
  4. Grant accessibility or automation permissions when using global trigger or text insertion features.
  5. Configure an ASR provider and, if needed, a text processing provider.
  6. Run the connection test before using an external provider.

Permissions

NuType may request these macOS permissions depending on the selected features:

  • Microphone: recording speech for transcription.
  • Speech Recognition: using Apple Speech when selected.
  • Accessibility and Automation: triggering NuType globally and inserting text into the current app.

Users can revoke permissions in macOS System Settings at any time.

AI and ASR Providers

NuType does not include developer-owned AI credentials. Users can configure local or external providers themselves. API keys are stored only in the macOS Keychain.

  • oMLX local ASR default URL: http://127.0.0.1:8000/v1.
  • oMLX model currently exposed in NuType: Qwen3-ASR-1.7B-bf16.
  • Ollama is used for local text processing and quality analysis. LM Studio is not exposed as a NuType 1.0 AI provider.

Purchase and Restore

NuType Pro is unlocked through Apple In-App Purchase. Purchase and restore actions are available in the Premium settings section. Purchases are processed by Apple, and NuType reads StoreKit purchase state to unlock Pro features.

Data and Privacy

NuType does not operate a developer-owned backend, AI proxy, analytics SDK, advertising SDK, or third-party login. User audio and text are processed locally or sent directly to the provider configured by the user.

Read the full privacy policy: NuType Privacy Policy.

Useful Details for Support Requests

When reporting a problem, include:

  • macOS version.
  • NuType version and build number.
  • Selected ASR provider and model.
  • Selected text processing provider and model.
  • Error message shown by NuType.
  • Whether the issue happens with Apple Speech, local oMLX, or an external provider.

Do not include real API keys, private recordings, personal text, Apple ID credentials, or payment information in support requests.
