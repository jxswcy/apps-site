NuIPTVSupport

Help for adding IPTV sources, EPG setup, playback, iCloud sync, AI subtitle configuration, and Pro features.

Getting started

Add a legal IPTV source you control or are allowed to use. NuIPTV does not include channels, live TV content, or content recommendations.

Source import

Use a URL, local file, or pasted text to import M3U, M3U8, or compatible text sources. If a source fails, check the URL, encoding, network access, and whether the source requires custom headers.

EPG and channel matching

Add an XMLTV EPG source, refresh it, and review channel matching. Program data depends on the EPG service you provide.

Playback and external players

NuIPTV uses Apple native playback for compatible streams. Some stream formats may not work with AVPlayer and may require an external player option when available.

iCloud, Pro, and AI subtitles

iCloud sync, AI subtitles, and advanced settings may require NuIPTV Pro. AI features require your own compatible provider endpoint and API key.

Contact support

If you need help, use the support channel listed on the App Store product page when available, and include enough detail to reproduce the issue.

Quick help

When reporting an issue, include your device, system version, NuIPTV version, source format, playback URL type, and the error shown in the app.
