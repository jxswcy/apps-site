NuDrillSupport

Help for importing JSON question banks, practice, mock exams, review, statistics, Markdown export, and local data control.

Getting started

Open NuDrill, import a local JSON question bank, then choose regular practice, mock exam, review, statistics, or export from the app.

JSON import

NuDrill expects a compatible JSON question-bank structure. If import fails, check file encoding, required fields, question type names, choices, answers, and whether the file is valid JSON.

Practice and mock exams

Regular practice gives immediate feedback and explanations. Mock exams can be configured by question count, type, and time limit.

Review, tags, and statistics

Use wrong-answer review, favorites, tags, and local statistics to focus future practice on weaker areas.

Markdown export and local data

Export review notes or wrong-answer summaries as Markdown files. You can clear local app data from Settings when you want to reset NuDrill.

Contact support

If you need help, email jxswcy@gmail.com. If the issue is import-related, include a small sample JSON when possible.

Quick help

For support, email jxswcy@gmail.com. Include your device, system version, NuDrill version, JSON file size, question type, and the import or practice step that failed.
