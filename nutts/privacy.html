NuTTSPrivacy Policy

NuTTS turns your imported documents into playable audio on iPhone, iPad, and Mac. This policy explains what data is processed, where it is stored, and when configured speech or text model services are used.

Documents and generated audio

NuTTS stores imported or created text, document titles, folder membership, extracted PDF, DOCX, Markdown, or TXT content, paragraph timing markers, synthesis status, generated audio files, playback progress, playback queue, and export records so you can manage and replay them in the app.

API keys and settings

If you configure Alibaba Cloud Model Studio or an online custom compatible endpoint, your API key is stored in the system Keychain on the current device. API keys are not hard-coded by NuTTS, are not stored in the SwiftData document library, and are not synced through iCloud.

Speech and text model requests

When you generate audio or use text-model assistance, NuTTS sends only the needed document text, model, voice, scene instructions, and related request fields to the service endpoint you configured. The default speech service is Alibaba Cloud Model Studio, and you may choose an online custom Qwen-TTS compatible speech endpoint. Text-model assistance can use Alibaba Cloud Model Studio or your OpenAI Chat Completions compatible HTTPS endpoint for PDF paragraph recovery, connection tests, or pronunciation-mark assistance that you explicitly enable. NuTTS does not operate its own relay server for this content. The default Qwen-TTS synthesis path does not invoke AI homophone-replacement preprocessing and does not add built-in pronunciation prompts by default.

iCloud sync

If you enable iCloud, devices signed in to the same Apple ID may sync documents, text, audio summaries, audio data, paragraph timing markers, synthesis task status, and non-sensitive settings. API keys are not synced. Local import source paths stay on the current device and are not uploaded by NuTTS explicit CloudKit document snapshots; old remote source-path values are not written back into local documents. Turning off NuTTS iCloud sync does not automatically delete data already synced to Apple iCloud.

Diagnostics, ads, analytics, and tracking

NuTTS may keep local diagnostic details such as generation duration, error type, request status, provider, model, request id, and response byte count. Default diagnostics and errors do not include document text, audio, API keys, or full third-party HTTP response bodies. NuTTS does not include third-party advertising SDKs, third-party analytics SDKs, IDFA, ATT prompts, SKAdNetwork configuration, or cross-app tracking technologies.

Deletion, exports, and built-in demo

Deleting a document in NuTTS also clears related local audio, segment cache, and synthesis tasks. Uninstalling the app removes data in the local app container, but it may not remove copies already synced to iCloud. Exported audio files are saved where you choose and must be managed in Finder or Files. NuTTS includes a self-written demo text and local demo audio for first launch and App Review; it does not come from third-party articles and does not trigger network requests.

Support

If you contact support at jxswcy@gmail.com, the information you choose to provide is used only to respond to your request and improve NuTTS.

Privacy at a glance

NuTTS keeps your library on device by default, uses your configured provider only when needed, and does not include ads, analytics, or tracking.

  • Documents and generated audio are stored locally unless iCloud sync is enabled.
  • API keys stay in device Keychain and do not sync through iCloud.
  • Speech and text requests are sent only to endpoints you configure.
  • No ads, third-party analytics, IDFA, ATT, or cross-app tracking.
