NuFile Support

Help for OFD/PDF conversion, watermarking, invoice CSV, and local file workflows.

Getting started

Add OFD or PDF files from Files/Finder, then review the input queue before exporting generated PDFs.

Conversion and watermarking

OFD files are converted to PDF. PDF files can receive your configured text watermark and export as new copies.

Invoice reports

Review extracted invoice fields before using them for file naming or exporting an invoice CSV report.

Files and privacy

NuFile works with files and folders you select. Document processing happens locally on your device.

Contact support
