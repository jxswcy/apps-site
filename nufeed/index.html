NuFeed

NuFeed is an RSS and web subscription reader for iPhone, iPad, and Mac. It helps you read feeds, extract full articles, translate bilingual content, summarize long reads, and sync reading progress with iCloud.

Key features
  • RSS subscriptions, folders, unread state, and favorites.
  • Web subscriptions for sites without RSS feeds.
  • Full article extraction for sources that only publish summaries.
  • Bilingual translation and full-article summaries using your own AI API configuration.
  • iCloud sync for subscriptions, reading state, and favorites.
