How people use it

The registry entry includes a ready-to-run prompt seed so the plugin can be evaluated without guessing its expected workflow. 

Use the html-ppt-presenter-mode template to create a talk deck with speaker notes. First confirm the talk topic, duration (2-3 minutes per slide), and target audience. Then write 150-300 words of conversational presenter notes per slide (prompting signals, not a manuscript), with the presenter popup available via the S key.
